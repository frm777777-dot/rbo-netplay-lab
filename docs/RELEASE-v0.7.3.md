# v0.7.3 — 방 코드 없이 IP와 포트로 접속

친구가 Join을 실행할 때마다 방 코드를 입력하던 단계를 없앴습니다. 호스트는 인원을 선택해 서버를 열고, 친구는 호스트의 IP와 포트만 입력하면 됩니다. 방 이름이나 비밀번호를 만들 필요가 없습니다.

- 이전 IP·포트 기억, Enter로 유지, 접속 실패 후 수정·재시도를 유지합니다.
- 자동 재접속 시 기존 1P·2P·3P 자리를 찾는 개인 연결 정보는 유지합니다. 호스트 권한도 별도로 확인합니다.
- v0.7.2의 한글 보스 이벤트 수정, 볼륨 조절과 싱글·온라인 저장 분리를 포함합니다.

**호스트와 친구 모두 v0.7.3으로 업데이트하세요.** 게임과 접속기를 종료한 뒤 ZIP을 기존 접속기 폴더에 덮어쓰면 됩니다. `saves`, `join-settings.json`, `game-settings.json`, `audio-settings.json`은 보존하세요. 게임 원본은 ZIP에 포함하지 않습니다.

방을 열어 둔 동안 접속 가능한 IP와 포트를 아는 사람은 빈 자리에 참가할 수 있습니다. 기존 공유기 포트 연결·방화벽 설정은 계속 사용합니다.

자동 검사 183개, 2·3인 소켓 접속·재접속, 별도 무음 게임 2개의 실제 Host/Join 실행을 확인했습니다. 다른 PC의 인터넷 재시험을 수행한 결과는 아닙니다.
