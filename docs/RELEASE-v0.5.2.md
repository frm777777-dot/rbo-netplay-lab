# v0.5.2 — Join IP·포트 기억과 수정

Join에서 마지막으로 입력한 **IP와 포트**를 기억합니다. 다음 실행 때 표시되는 `[이전 값]`을 **Enter로 그대로 사용**하거나, **새 값을 입력해 변경**할 수 있습니다. 처음 포트 기본값은 47624입니다.

게임이 열리기 전 접속에 실패하면 실행기를 닫지 않고 선택할 수 있습니다.

- **Enter:** 같은 값으로 다시 시도
- **2:** IP·포트·방 코드를 수정한 뒤 다시 접속
- **3:** 종료

접속 설정은 실행기 폴더의 **join-settings.json**에 저장합니다. 방 코드는 매번 입력하며 파일에 저장하지 않습니다. 잘못된 IP·포트는 다시 입력하도록 안내하고, 설정 파일을 읽을 수 없으면 새로 입력할 수 있습니다. 파일 저장 실패만으로 이번 접속을 막지는 않습니다.

진행 중인 게임과 자동 재접속은 현재 방의 주소를 사용합니다. 다른 주소로 바꾸려면 세션을 끝내고 Join을 다시 실행하세요.

**v0.5.1과 함께 접속할 수 있습니다.** 세이브·한글화·자동 복구는 유지됩니다. 새 폴더에 업데이트했다면 기존 **saves 폴더와 join-settings.json**을 옮기세요. 게임 원본·개인 접속 설정·저장·로그는 배포 ZIP에 포함하지 않습니다.

값 저장·재사용·수정, 잘못된 입력, 손상된 설정, 저장 실패, 실제 TCP 접속 거절 후 수정·연결을 확인했습니다. 실제 2인 Host/Join 실행 경로도 120프레임으로 짧게 검사해 정상 종료를 확인했습니다. 게임 진행 로직과 통신 버전은 변경하지 않았습니다.

실행용 파일은 아래 **RBO-Netplay-Lab.zip**입니다.
