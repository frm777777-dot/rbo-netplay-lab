# v0.7.2 — 한글 패치의 몬스터 이벤트 오류 수정

3스테이지 보스전에서 Q 메뉴는 열리지만 모든 캐릭터와 전투 진행이 멈추던 원인을 수정했습니다. 한글 패치가 화면 대사와 내부 함수 이름을 구별하지 못해, 구미호가 월야화 스크립트의 피격·사망 동작을 호출할 때 존재하지 않는 이름을 찾고 있었습니다.

- 구미호의 호출 이름 2곳과 드레이크·하티베베의 같은 유형 2곳을 번역 대상에서 제외했습니다. 화면에 표시되는 UI·대사의 한글화는 유지합니다.
- 모든 게임 스크립트의 공개 함수 이름과 참조가 보존되는지 검사하고, 한글 자료를 생성할 때 내부 이름을 번역하려 하면 중단합니다.
- 별도 무음 게임에서 수정 전 두 호출의 이름 검색 실패와 수정 후 정상 검색을 확인했습니다. 실제 보스전 전체를 다시 플레이한 검사는 아닙니다.
- 게임 원본·저장 형식·입력 처리·온라인 복구 방식·볼륨 기능은 변경하지 않았습니다. 한글 싱글에도 적용됩니다.

**호스트와 친구 모두 업데이트해야 합니다.** 한글 자료의 검증 값이 달라 이전 접속기와는 연결되지 않습니다. 게임 창과 실행기를 종료한 뒤 실행용 ZIP을 기존 접속기 폴더에 덮어쓰세요. `saves`, `join-settings.json`, `game-settings.json`, `audio-settings.json`은 보존하세요. 게임 원본과 개인 저장은 ZIP에 포함하지 않습니다.

이미 중단된 방의 메모리 상태를 현장에서 수정하는 기능은 없습니다. 업데이트 후 방을 다시 열고 저장된 캐릭터로 진행하세요. 중단된 보스전 위치를 그대로 복원하지는 않습니다.
