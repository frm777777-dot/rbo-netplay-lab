# v0.5.1 — 한글 설정 프로그램과 개인 화면·소리 설정

온라인에 들어가기 전에 **Settings-Online.cmd**로 한글 EX3 설정 창을 열 수 있습니다. 각 PC의 키·화면 크기·소리·화면 갱신·텍스처 화질을 설정하고 저장한 뒤 Host/Join을 실행하세요.

호스트와 친구 모두 **자신의 1P 키 설정**을 사용합니다. 각 동작의 오른쪽 칸을 선택하고 원하는 키를 누른 뒤 **확인 → 저장**을 누르세요. 친구가 로컬 2P·3P 키를 따로 설정할 필요는 없습니다. 온라인은 키보드와 창 모드를 사용합니다. 전체 화면 선택은 원본 게임을 직접 실행할 때 적용됩니다.

기존 온라인 실행기는 키 설정만 가져왔지만, 이제 화면·소리 설정도 각 PC에서 가져옵니다. 소리를 끈 참가자와 켠 참가자의 메뉴 전환 시점이 달라지던 문제도 수정했습니다. 화면 전환의 프레임 대기는 유지하면서 로컬 음악의 재생 종료를 추가로 기다리지 않도록 했습니다.

**호스트와 친구 모두 v0.5.1로 업데이트하세요.** 메뉴 전환 처리가 달라 이전 버전과 연결되지 않습니다. **기존 saves 폴더를 보존**하면 1P·2P·3P 저장을 이어서 사용할 수 있습니다. v0.5.0의 자동 재접속·스테이지 복구·플레이 한글화는 유지됩니다.

원본 **RBOEx3Config.exe**와 Windows 10 1903 이상이 필요합니다. 한글 설정 도구는 원본을 확인하고 같은 폴더에 **RBOEx3Config-KO.exe** 사본을 만들어 실행합니다. 원본 게임·설정 실행 파일, 캐릭터 저장, 개인 로그는 배포물에 포함하지 않습니다.

한글 설정 창·키 설정 창의 표시와 화면·소리·화질 설정 저장을 확인했습니다. 서로 다른 해상도·소리·화질·화면 갱신 설정으로 실제 게임 3개를 2,400프레임 실행해 1→2스테이지 전환, 입력·검사 상태 및 세 캐릭터 저장 사본 일치를 확인했습니다. 시험 시간을 줄이기 위해 클리어 조건만 시험 코드로 설정했습니다. 한 PC에서의 검사이며 모든 스테이지·설정 조합이나 서로 다른 PC의 장시간 플레이를 검증한 것은 아닙니다.

실행용 파일은 아래 **RBO-Netplay-Lab.zip**입니다. 자세한 사용법은 [README](https://github.com/frm777777-dot/rbo-netplay-lab#readme), 검사 결과는 [검증 기록](https://github.com/frm777777-dot/rbo-netplay-lab/blob/main/docs/VALIDATION.md)을 참고하세요.
