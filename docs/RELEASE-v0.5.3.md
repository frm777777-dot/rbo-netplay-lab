# v0.5.3 — 한글 싱글플레이와 저장 분리

**Single-Korean.cmd**를 실행하면 한글 패치를 적용해 혼자 플레이할 수 있습니다. 기존 **Launch-RBO.cmd**도 같은 한글 싱글 실행기로 연결됩니다. 서버·IP·방 코드는 필요하지 않습니다.

타이틀에서 시작하고 1P로 캐릭터를 선택하거나 만드세요. **Settings-Online.cmd**에서 지정한 1P 키·화면·소리 설정을 사용합니다. 창 모드·키보드를 지원하며 플레이 시간 제한은 없습니다.

싱글과 온라인은 저장을 따로 관리합니다.

| 모드 | 저장 위치 |
| --- | --- |
| 한글 싱글 | `saves/single/current.json` |
| 온라인 호스트 | `saves/host/current.json` |
| 온라인 친구 사본 | `saves/replicas/<저장 ID>/current.json` |

**첫 싱글 실행은 새 캐릭터 목록으로 시작합니다.** 이후에는 싱글 저장을 이어서 사용하며, 온라인 1P·2P·3P 저장과 원본 게임의 개인 저장을 가져오거나 덮어쓰지 않습니다. 게임의 원래 저장 시점을 사용하므로 전투 중 위치를 그대로 이어가는 저장은 아닙니다. 종료할 때는 게임 창을 먼저 닫고 실행기의 종료 안내를 확인하세요.

온라인은 **v0.5.1·v0.5.2와 호환**됩니다. 기존 재접속·스테이지 복구·Join 주소 기억도 유지됩니다. 업데이트할 때 **saves 폴더 전체와 join-settings.json**을 보존하세요.

실제 EX3에서 새 싱글 캐릭터 생성·1스테이지 진입·저장 후 재실행 불러오기를 확인했습니다. 온라인 호스트·친구 사본·원본 설치의 저장 파일은 검사 전후 동일했고, 소켓 없이 실행되는 것도 확인했습니다. 모든 스테이지를 완주한 검사는 아닙니다.

실행용 파일은 아래 **RBO-Netplay-Lab.zip**입니다. 게임 원본은 별도로 준비해야 합니다. 게임 원본·개인 접속 설정·저장·로그는 배포 파일에 포함하지 않습니다.
