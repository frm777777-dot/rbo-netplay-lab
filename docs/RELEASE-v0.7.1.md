# v0.7.1 — 게임 전체 볼륨 조절

`Volume-Settings.cmd`에서 0~100% 볼륨을 설정할 수 있습니다. 예를 들어 `20`을 입력하면 20%로 기억합니다. `0`은 무음, Enter는 현재 설정 유지입니다. `Settings-Online.cmd`에서도 볼륨을 먼저 설정할 수 있습니다.

- 싱글·Host·Join에 적용됩니다. 이 버전으로 게임을 실행한 뒤에는 플레이 중에도 변경할 수 있습니다.
- 배경 음악과 효과음을 함께 조절합니다. 각 PC의 `audio-settings.json`에 저장합니다.
- Windows의 해당 게임 소리 세션만 조절합니다. 스피커 전체·다른 앱·친구 PC의 볼륨 및 기존 Windows 음소거는 유지합니다.
- 소리 장치 생성 후 적용되어 시작 직후에는 짧은 반영 지연이 있을 수 있습니다. 기존 게임 설정에서 소리를 꺼두었다면 볼륨을 올려도 소리는 나지 않습니다.
- 소리 제어 오류는 게임이나 온라인 연결을 종료하지 않습니다. 게임 진행·복구·저장 형식은 바꾸지 않았습니다.

**v0.7.0과 함께 접속할 수 있습니다.** 볼륨 조절을 사용할 PC만 업데이트해도 됩니다. 게임과 실행기를 닫은 뒤 압축 파일을 기존 접속기 폴더에 덮어쓰세요. `saves`, `join-settings.json`, `game-settings.json`, `audio-settings.json`은 보존하세요. 게임 원본은 포함하지 않습니다.
