# v0.6.0 — 연결 유지 복구와 공격 동기화 개선

일시적인 인터넷 연결 끊김 때문에 게임까지 다시 시작되던 동작을 바꿨습니다. 연결을 기다리는 동안 현재 게임과 입력 순서를 보관하고, 다시 연결되면 같은 위치에서 계속합니다. 이미 처리한 입력이나 저장은 중복 적용하지 않습니다.

공격 명령은 전체 스크립트의 지문과 내부 위치로 비교합니다. 사용이 끝난 명령 저장 공간의 잔여 값은 활성 명령 목록과 구분합니다. 직업 자동 검사에서 발견한 검사 캐릭터의 공격 중 잘못된 진행 차이 판정도 이 공통 처리로 해결했습니다. 동작 기록·활성 공격 판정·충돌 사각형 자료는 내용으로 검증합니다.

실제 진행 차이나 게임 충돌은 스테이지 시작 지점에서 복구합니다. 호스트의 1P·2P·3P 저장, 친구 PC의 사본, 분리된 싱글 저장을 유지합니다. 문제가 생기면 각 참가자의 상세 진단을 호스트의 `logs/<세션>/events`에 모으며, 별도 외부 서버로 전송하지 않습니다.

**호스트와 친구 모두 v0.6.0으로 교체해야 합니다.** v0.5.x와는 통신·상태 비교 방식이 달라 함께 접속할 수 없습니다.

1. 게임과 실행기를 종료합니다.
2. 아래 `RBO-Netplay-Lab.zip`을 풀어 기존 실행기 폴더에 덮어씁니다.
3. 기존 `saves` 폴더와 `join-settings.json`을 보존합니다.
4. 호스트는 `Host-Online.cmd`, 친구는 `Join-Online.cmd`로 다시 접속합니다. TCP 포트는 기존과 같습니다.

한글 패치·한글 설정 프로그램·같은 키 구성의 독립 조작을 유지합니다. 게임 원본은 포함하지 않습니다. 개발 시험은 별도 복사본에서 무음으로 실행하며 평소 플레이의 소리 설정은 바꾸지 않습니다.

2·3인 연결 단절, 실제 진행 차이, 네이티브 충돌, 저장 유지와 기본 무제한 실행기의 정상 종료를 검사했습니다. 직업·성별 14종을 7조합으로 나눠 실제 공격 판정이 발생하는 전투 입력을 재생했고, 두 게임의 진행이 일치했습니다. 세부 결과와 재현 범위는 [검증 기록](https://github.com/frm777777-dot/rbo-netplay-lab/blob/main/docs/VALIDATION.md)에 정리했습니다. 모든 기술·스테이지의 완주나 서로 다른 PC의 장시간 플레이까지 검증한 것은 아닙니다.
