# v0.5.4 — 공격 명령의 주소 차이로 인한 반복 복구 수정

활 공격 뒤 게임 창이 닫혔다가 다시 열리던 문제를 수정했습니다. 두 PC에서 같은 공격을 처리해도 내부 명령 자료의 주소는 달랐고, 기존 상태 검사가 이를 진행 차이로 판정했습니다.

수정은 특정 활이나 스킬에 대한 예외가 아닙니다. 게임의 **공통 명령 목록 35칸과 여섯 연결 목록 전체**에서 주소와 데이터를 구분합니다. 활성 명령의 앞 64바이트와 연결 순서를 비교하며, 캐릭터·위치·난수 등 기존 진행 검사는 유지합니다. 실제 값이 달라졌는데 오류를 무시하고 계속 플레이하도록 바꾼 것은 아닙니다.

실제 중단 직전의 두 플레이어 입력을 재생하고 화면 크기·화질·소리 설정을 서로 다르게 적용했습니다. 수정 전 1,560프레임에 중단되던 검사가 수정 후 1,700프레임까지 두 게임의 상태·입력 일치로 완료됐습니다. 검사는 한 Windows PC의 분리된 게임 두 개를 사용했습니다. 모든 직업·스킬·스테이지의 완주를 검증한 것은 아닙니다.

**호스트와 친구 모두 v0.5.4로 업데이트해야 합니다.** 상태 비교 형식이 달라 v0.5.3 이하와는 접속되지 않습니다.

1. 게임과 Host/Join 실행기를 종료하세요.

3. **saves 폴더와 join-settings.json은 보존**하고 Host/Join을 다시 실행하세요.
