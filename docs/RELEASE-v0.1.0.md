RBO 3인 온라인 연결 실험판의 첫 공개 버전입니다.

**친구에게는 `RBO-Netplay-Lab.zip`을 전달하세요.** 아래 Assets의 해당 파일을 받아 압축을 풀면 됩니다. GitHub가 자동으로 제공하는 Source code 압축본은 실행용이 아닙니다.

1. 호스트는 `Host-Online.cmd`, 친구 두 명은 `Join-Online.cmd`를 실행합니다.
2. 각자 준비한 일본어판 EX3 게임 폴더를 입력합니다.
3. 친구는 호스트의 주소와 방 코드를 입력합니다.
4. 모두 자신의 1P 키 설정을 사용합니다. 서버가 각자의 입력을 1P·2P·3P로 분리합니다.

Python 실행 구성요소를 포함했습니다. **RBO 게임 원본은 포함하지 않습니다.**

현재는 Stage 15, 25레벨 마법사 3명의 고정 시험 세션이며 최대 7,200 논리 프레임 뒤 종료됩니다. 일반 캐릭터 선택·스테이지 이동·저장·재접속은 미구현입니다. 실제 키보드 입력을 포함해 같은 PC의 게임 3개에서 7,200프레임 진행 일치를 확인했습니다. 다른 PC와 외부 인터넷 환경은 아직 검증하지 않았습니다.

외부 접속에는 호스트의 TCP 47624 포트 연결과 방화벽 허용이 필요합니다. 자세한 준비 사항은 저장소 README와 압축파일의 `온라인 시험판 사용법.txt`를 참고하세요.

첨부된 `SHA256SUMS.txt`에서 다운로드 파일의 SHA-256을 확인할 수 있습니다.
