# v0.6.2 — 전투 중 창 전환에 따른 재시작 수정

전투 중 Alt+Tab 등으로 다른 창으로 이동하면 일부 PC에서 사진 저장이 추가로 실행되어 난수 상태가 달라졌습니다. 온라인 상태 검사가 이를 진행 차이로 판단해 게임을 다시 열고 스테이지를 복구하던 문제를 수정했습니다.

- 창 활성화·비활성화 이벤트에서 사진 저장을 실행하지 않고, 기존 스테이지 종료 시점에 처리합니다.
- 전투·난수 비교, 자동 연결 복구, 한글 패치, 게임 경로 기억, 1P·2P·3P 세이브와 싱글·온라인 저장 분리는 유지합니다.
- 원본 게임 파일을 변경하지 않으며 온라인 실행 중인 임시 게임에만 적용합니다.

**호스트와 친구 모두 업데이트해야 합니다.** v0.6.0·v0.6.1을 포함한 이전 버전과는 연결되지 않습니다. 게임과 실행기를 종료한 뒤 ZIP을 기존 실행기 폴더에 덮어쓰세요. `saves`, `join-settings.json`, `game-settings.json`을 보존하세요. 게임 원본은 ZIP에 포함하지 않습니다.

같은 PC의 분리된 무음 게임에서 원래 창 활성화 처리 함수를 호출해 수정 전의 난수 불일치·스테이지 복구를 재현했습니다. 수정 후 반복 호출, 다음 스테이지 진행, 세 캐릭터 저장 보존을 확인했습니다. 실제 인터넷의 다른 PC에서 키를 누른 검사는 아니며, 다른 원인의 충돌까지 모두 해결됐다는 의미는 아닙니다.
