# v0.7.0 — 일시정지 진단·같은 창에서 스테이지 복구

일반 전투에서 진행 차이가 나면 살아 있는 게임까지 종료하던 복구 절차를 변경했습니다. 이제 전원이 멈춘 상태에서 차이를 분류하고, 가능한 경우 **게임 창을 유지한 채 스테이지 시작 지점을 다시 불러옵니다.**

- 검증된 화면 표시 값은 전투 검사와 구분해 기록하며, 그 차이만으로 재시작하지 않습니다. 위치·체력·공격·난수 등 전투 값의 검사는 유지합니다.
- 같은 창 안에서 기존 장면을 정리하고 스테이지를 초기화합니다. 오래된 입력은 새 복구 세대에 전달되지 않습니다.
- 복구 중 만들어진 미확정 임시 저장은 버리고, 호스트가 확정한 1P·2P·3P 저장을 보존합니다. 싱글·온라인 저장 분리와 키·소리·게임 경로 설정은 유지합니다.
- 실제 게임 충돌, 메뉴·장면 전환 중 오류, 장면 복구 실패에는 기존 게임 재실행 복구를 사용합니다. 반복 실패 시 타이틀 복구·중단 정책도 유지합니다.

**스테이지 처음부터 다시 진행합니다. 문제 직전 위치를 복원하거나 지난 입력을 자동 재생하는 기능은 이번 버전에 포함하지 않습니다.**

**호스트와 친구 모두 v0.7.0으로 업데이트하세요.** 이전 버전과는 연결되지 않습니다. 게임과 실행기를 종료한 뒤 ZIP을 기존 접속기 폴더에 덮어쓰고 `saves`, `join-settings.json`, `game-settings.json`을 보존하세요. 게임 원본은 포함하지 않습니다.

한 Windows PC의 분리된 무음 게임에서 2인 반복 복구·3인 복구 후 같은 프로세스와 창 유지, 시작 상태 복원, 다음 스테이지 진행, 세 캐릭터 저장 일치를 확인했습니다. 장면 복구 실패를 주입했을 때 기존 재실행으로 전환되는 것도 검사했습니다. 서로 다른 PC의 실제 인터넷·전 스테이지 장시간 검사를 완료한 것은 아닙니다.
