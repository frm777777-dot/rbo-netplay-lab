# v0.6.1 — 게임 폴더 기억

Join을 실행할 때마다 게임 폴더를 다시 입력해야 하던 문제를 수정했습니다. 이전 버전은 IP·포트만 기억하고 게임 폴더는 저장하지 않았습니다.

- 처음 선택한 게임 폴더를 `game-settings.json`에 저장하고 다음 실행부터 자동으로 사용합니다.
- Join·Host·싱글·설정 프로그램에 함께 적용됩니다.
- 폴더를 바꾸려면 새로 추가한 **`Select-Game.cmd`**를 실행하세요. 게임은 켜지 않고 폴더만 변경합니다.
- 기억한 폴더가 없어지거나 설정 파일이 손상되면 다시 선택할 수 있습니다. 저장에 실패하면 안내하고 이번 실행은 입력한 경로로 계속합니다.

게임과 실행기를 종료한 뒤 아래 ZIP을 **기존 실행기 폴더에 덮어쓰세요.** 업데이트 후 최초 한 번 게임 폴더를 입력하면 됩니다. `saves`, `join-settings.json`, `game-settings.json`은 보존하세요. 다른 폴더에 새로 풀면 기존 저장·설정도 함께 옮겨야 유지됩니다.

**v0.6.0 호스트에 v0.6.1 친구가 접속할 수 있습니다.** 게임 진행·통신 방식은 바꾸지 않았으므로, 호스트가 이미 v0.6.0이면 친구만 먼저 업데이트해도 됩니다. v0.5.x와는 호환되지 않습니다.

게임 원본은 포함하지 않습니다. 폴더 기억·변경·이동·잘못된 설정·저장 실패·별도 실행 후 재사용·각 실행기의 경로 사용을 게임 실행 없이 검사했습니다. 한글 패치, 싱글·온라인 저장 분리와 전원 세이브를 유지합니다.
