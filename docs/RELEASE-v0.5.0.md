# v0.5.0 — 자동 복구와 한글 플레이 화면

연결 끊김·진행 불일치·게임 비정상 종료가 나면 방을 바로 끝내는 대신, 전원이 다시 접속하고 스테이지 시작 지점부터 재개합니다. 친구의 2P·3P 자리와 마지막으로 확인된 전원 저장본을 유지합니다.

## 사용하기

호스트와 친구 모두 이 릴리스의 **RBO-Netplay-Lab.zip**을 받아 완전히 풀어 주세요. `Source code`는 실행용 패키지가 아닙니다. 기존 폴더에 업데이트하거나, 새 폴더로 옮길 때 **기존 `saves` 폴더를 함께 복사**하세요. 게임 원본은 별도로 필요합니다.

호스트는 `Host-Online.cmd`, 친구는 `Join-Online.cmd`로 실행합니다. 본인 포함 2명 또는 3명을 지원하며, 주소·TCP 47624·방 코드 설정은 이전과 같습니다. 각자 같은 1P 키 설정을 사용해도 자기 캐릭터에만 전달됩니다.

## 복구 방식

- 오류가 확인되면 자동 재접속 후 게임 창을 다시 엽니다. **실행기 창은 닫지 마세요.**
- 스테이지에 들어갔을 때의 파티·캐릭터·난수를 함께 복원합니다. 스테이지 안에서 진행한 미저장 이동·경험치·아이템은 되돌아갑니다.
- 1P·2P·3P의 확정된 저장은 호스트와 친구 사본 모두 유지합니다. 2인 플레이에서 사용하지 않은 3P 저장도 지키며, 불일치한 프레임의 저장은 채택하지 않습니다.
- 전투 밖에서 문제가 생기거나 복구가 반복되면 저장본을 유지한 채 타이틀로 돌아갑니다. 최대 약 5분간 다시 연결하며, 반복 실패 시 이유를 알리고 종료합니다.
- 사용자가 게임 창을 정상적으로 닫으면 방 전체가 종료됩니다. 호스트 실행기·PC가 종료된 경우에는 새 방에서 저장 캐릭터로 시작합니다.

## 한글화

온라인 실행 시 자동 적용합니다. 플레이 메뉴·직업·기술·지도·전투 안내·결과·순위 등의 그림 글씨 495곳, 대사·메시지 584개(중복 포함 883곳)를 번역했습니다. 원본 게임의 여섯 비트맵 글꼴에 561개 한글 글자 모양을 추가했습니다.

이번 범위에서 제작진·유저 **편지 코너는 제외**했습니다. 원본 음성·이름 입력 방식과 작품명·개인 이름 등의 고유 표기는 유지합니다. 직접 원본 EXE를 실행할 때는 한글 패치가 적용되지 않습니다.

원본 PAC·EXE는 수정하지 않습니다. 배포물에는 연결 프로그램, Python, 직접 작성한 한글 변경분만 포함하며 완전한 게임 자료·영어 패치 파일·개인 저장·로그는 포함하지 않습니다.

## 확인한 범위

한 Windows PC의 분리된 실제 게임에서 2·3인 연결 끊김, 상태 불일치, 게임 강제 종료·실제 예외를 주입하여 복구와 다음 스테이지 진행을 확인했습니다. 세 캐릭터 저장과 친구 사본도 비교했습니다. 통신 36개·복구 12개·저장 3개·한글 자료 3개 검사를 통과했습니다.

한글 자료는 명령 코드·이미지 크기·기존 글꼴·원본 파일을 보존하는지 검사했고, 실제 화면에서 메뉴·직업·한글 글꼴 표시를 확인했습니다. 스테이지 전환 시험은 클리어 조건만 인위적으로 만들었습니다. 서로 다른 PC의 장시간 플레이나 모든 보스·기술·대사를 직접 완주하며 검증한 결과는 아닙니다.
