# RBO Netplay Lab

**[Windows 시험판 다운로드 — ZIP 약 12MB](https://github.com/frm777777-dot/rbo-netplay-lab/releases/download/v0.1.0/RBO-Netplay-Lab.zip)** · [릴리스 안내](https://github.com/frm777777-dot/rbo-netplay-lab/releases/tag/v0.1.0)

Ragnarok Battle Offline EX3를 **호스트 1명 + 친구 2명**이 각자 PC에서 실행하도록 만든 온라인 연결 실험판입니다. 호스트 PC가 서버 역할을 하므로 별도의 유료 서버나 화면 전송 서비스는 사용하지 않습니다.

> **v0.1.0은 고정된 시험 스테이지용입니다.** Stage 15, 25레벨 마법사 3명을 사용합니다. 일반 캐릭터 선택·스테이지 이동·저장·재접속은 아직 지원하지 않습니다. 같은 PC에서 게임 3개를 연결한 검사는 통과했지만, 서로 다른 PC와 실제 외부 인터넷 연결은 아직 검증하지 않았습니다.

## 친구가 실행하는 방법

1. 위 **Windows 시험판 다운로드**를 눌러 `RBO-Netplay-Lab.zip`을 받습니다. GitHub의 `Code → Download ZIP`이나 `Source code` 압축본은 실행용 패키지가 아닙니다.
2. 압축을 완전히 풀고 `Join-Online.cmd`를 실행합니다. Python은 패키지에 포함되어 있어 따로 설치하지 않아도 됩니다.
3. 자신의 게임에서 **일본어판 `rbo_ex3.exe`와 `DATA`가 함께 들어 있는 폴더**를 입력합니다.
4. 호스트에게 받은 **접속 주소와 방 코드**를 입력합니다.
5. 게임 창을 선택한 뒤 **자신의 로컬 1P 키 설정**으로 조작합니다. 친구는 자동으로 2P 또는 3P가 됩니다.

게임 원본은 포함되어 있지 않습니다. 세 사람 모두 같은 일본어판 EX3 4.0 실행 파일과 기본판·EX1·EX2·EX3 데이터를 준비해야 합니다. 실행 파일이나 게임 데이터가 다르면 연결을 거부합니다.

## 호스트가 실행하는 방법

1. 같은 압축파일에서 `Host-Online.cmd`를 실행합니다.
2. 게임 폴더를 입력하고, 화면에 나온 방 코드와 접속 주소를 친구 두 명에게 전달합니다.
3. 세 사람이 준비되면 시작합니다. 시작 화면은 약 30초간 표시됩니다.

외부 인터넷에서 접속하려면 **TCP 47624**가 호스트 PC로 들어올 수 있어야 합니다. 공유기의 포트 연결과 Windows 방화벽 허용은 별도로 설정해야 하며, 실행기가 자동으로 바꾸지는 않습니다. CGNAT·이중 공유기 환경은 추가 설정이나 가상 사설망이 필요할 수 있습니다. 중계 서버와 자동 포트 개방은 제공하지 않습니다.

## 세 사람이 같은 키를 써도 됩니다

모든 PC에서 로컬 **1P 키 설정**을 읽고, 서버가 연결별로 배정한 캐릭터에게만 전달합니다. 원격 PC의 키보드 이벤트를 그대로 재현하는 방식이 아닙니다.

| PC | 사용하는 키 설정 | 조작하는 캐릭터 |
| --- | --- | --- |
| 호스트 | 자신의 1P 설정 | 1P |
| 친구 A | 자신의 1P 설정 | 2P |
| 친구 B | 자신의 1P 설정 | 3P |

세 사람이 모두 Z를 누르면 각자의 캐릭터가 공격합니다. 기본 설정은 **H/N/B/M 이동, Z/X/C/V 동작**입니다. 기존 키 설정 파일은 시험용 복사본으로 가져옵니다. 기본 Z키는 직접 조작까지 확인했으며, 사용자 지정 키와 패드는 별도 검증이 필요합니다.

## 현재 확인한 범위

- 실제 게임 3개를 TCP 서버에 연결한 자동 입력 2,400프레임 검사 통과.
- 동일한 Z키를 각 게임의 키 변환 경로에 넣는 2,400프레임 검사 통과.
- 실제 키보드 조작을 포함한 **7,200프레임에서 입력과 검사 대상 게임 상태 차이 0건**.
- 접속자별 슬롯 분리, 잘못된 입력 거부, 연결 종료 및 상태 불일치 중단 검사 통과.
- 호스트·친구 실행기를 통한 3인 세션 시작과 정상 종료 확인.

현재 세션은 최대 7,200 논리 프레임 뒤 종료됩니다. 화면에 기존 `DEMONSTRATION` 표시가 남아 있지만 동작 입력은 서버에서 실시간으로 받습니다. 전체 게임 메모리, 모든 스테이지, 인터넷 지연·손실, 다른 PC의 동일 진행을 보장하는 검사는 아닙니다. 자세한 범위는 [검증 기록](docs/VALIDATION.md)에 있습니다.

## 게임 파일과 기록

원본 실행 파일을 디스크에서 수정하지 않습니다. 임시 폴더의 시험용 게임 프로세스에 연결 모듈을 적용하며, 캐릭터 저장을 원본 게임에 되돌리지 않습니다. 접속용 방 코드는 매번 새로 생성됩니다. 현재 TCP 통신 자체는 암호화하지 않습니다.

지원하는 일본어판 EX3 실행 파일 SHA-256:

```text
05b14b047e49dabb026c96150f8d5aab497d20d9b2d52f5e59a8aef1af5b8dc0
```

실행 기록은 압축을 푼 폴더의 `logs`에 남습니다. 이 저장소에는 게임 데이터, 저장 파일, 개인 실행 로그, 접속용 방 코드를 올리지 않습니다. RBO 공식 프로젝트와는 별개의 실험 도구입니다.
