RBO 한글 싱글·2~3인 온라인 실험판 v0.6.0

호스트 PC가 서버를 실행합니다. 친구 1명 또는 2명과 플레이할 수 있습니다.
호스트와 친구 모두 v0.6.0로 업데이트하세요. 게임 원본은 따로 준비해야 합니다.
연결이 잠깐 끊겨도 게임 창과 현재 진행을 유지한 채 다시 연결합니다.
공격 명령을 전체 스크립트와 내부 위치로 비교합니다.
통신·상태 비교 방식이 달라져 v0.5.x와는 연결되지 않습니다. 아직 시험판입니다.
실행기와 게임을 종료한 뒤 기존 실행기 폴더에 새 파일을 덮어쓰세요.
saves 폴더와 join-settings.json은 보존하세요. 싱글·온라인 저장 형식과 위치는 유지됩니다.

한글 싱글플레이
Single-Korean.cmd를 실행하세요. 기존 Launch-RBO.cmd도 같은 한글 싱글로 실행됩니다.
서버·친구·IP·방 코드 없이 1P로 혼자 플레이합니다.
Settings-Online.cmd에서 정한 1P 키·화면·소리 설정을 사용합니다. 창 모드·키보드를 지원합니다.
싱글 저장: saves\single\current.json
온라인 호스트 저장: saves\host\current.json
온라인 친구 사본: saves\replicas\저장ID\current.json
싱글과 온라인은 캐릭터·진행을 가져오거나 덮어쓰지 않습니다.
처음 싱글을 실행하면 새 캐릭터 목록으로 시작하며, 이후에는 싱글 저장을 이어갑니다.
원본 개인 저장도 그대로 보존합니다. 업데이트할 때 saves 폴더 전체를 보존하세요.
전투 중 위치 저장이 아니라 게임의 원래 저장 시점을 사용합니다.
종료할 때는 게임 창을 먼저 닫고 실행기의 종료 안내를 확인하세요.

Join 주소 기억과 수정
입력한 IP와 포트는 실행기 폴더의 join-settings.json에 자동 저장합니다.
다음 실행에서 [이전 값]이 표시되면 Enter로 그대로 사용하거나 새 값을 입력하세요.
게임이 열리기 전 접속 실패 시 Enter는 재시도, 2는 IP·포트·방 코드 수정, 3은 종료입니다.
방 코드는 저장하지 않으므로 현재 방 코드를 입력하세요.
진행 중인 게임과 자동 재접속은 현재 방의 주소를 사용합니다.
다른 주소로 바꾸려면 현재 세션을 끝내고 Join을 다시 실행하세요.
업데이트를 새 폴더에 풀었다면 기존 join-settings.json도 옮겨야 주소가 유지됩니다.

온라인 실행 전 설정
Settings-Online.cmd를 실행하면 한글 EX3 설정 창이 열립니다.
게임 폴더를 묻는 경우 Host/Join과 같은 폴더를 입력하세요.
호스트와 친구 모두 각자 "1P 키 설정"을 엽니다.
동작 오른쪽 칸을 선택하고 원하는 키를 누른 뒤 확인 → 저장을 누릅니다.
2P/3P 키 설정은 한 PC에서 원래 로컬 게임을 할 때만 필요합니다.
화면 크기·소리·화면 갱신·텍스처 화질도 바꾸고 저장할 수 있습니다.
설정 창을 닫은 뒤 Host/Join을 실행하세요. 진행 중인 게임에는 다음 실행부터 반영됩니다.
온라인은 창 모드로 실행합니다. 전체 화면 선택은 원본 게임을 직접 실행할 때 적용됩니다.
원본 RBOEx3Config.exe를 보존하고 RBOEx3Config-KO.exe 한글 사본을 만듭니다.
설정 변경은 캐릭터 저장에 영향을 주지 않습니다. Windows 10 1903 이상이 필요합니다.

시작하기
1. 압축을 완전히 풀고 호스트는 Host-Online.cmd를 실행합니다.
2. 본인 포함 2명 또는 3명을 선택합니다. Enter만 누르면 2명입니다.
3. 각자 일본어판 rbo_ex3.exe와 DATA가 있는 EX3 4.0 게임 폴더를 입력합니다.
4. 친구는 Join-Online.cmd에서 호스트 주소·포트(기본 47624)·방 코드를 입력합니다.
5. 전원 연결 후 함께 게임 창이 열립니다. 1P가 타이틀에서 일반 게임을 선택합니다.
6. 캐릭터 화면에서 모두 Z로 참가하고, 각자 캐릭터를 선택하거나 만듭니다.
7. 선택이 끝나면 1P가 공통 메뉴의 출발과 스테이지를 결정합니다.
   첫 지도 선택은 Stage 1입니다. 예전처럼 데모 자동 시작을 기다리지 않습니다.

조작
모든 PC는 자신의 로컬 1P 키 설정을 사용합니다.
친구는 자동으로 2P/3P가 되므로 자신의 2P/3P 설정을 사용할 필요가 없습니다.
같은 Z키를 눌러도 각자 배정된 캐릭터에만 전달됩니다.
기본 이동: H 위 / N 아래 / B 왼쪽 / M 오른쪽.
기본 동작: Z 확인·공격 / X 취소·다른 동작 / C / V.
Q는 이름 입력 완료에 사용하며, 전투 중 일시정지는 1P의 Q 또는 F12입니다.
게임 창을 한 번 선택하고 조작하세요.
키보드 설정은 가져오고, 패드나 잘못된 키 번호는 온라인 복사본에서
기본 키보드 설정으로 바꿉니다. 원본 설정은 바꾸지 않습니다. 패드는 미지원입니다.
캐릭터 생성은 각자, 공통 메뉴와 출발·일시정지는 1P가 조작합니다.
게임 자체의 동일 캐릭터 조합 제한은 유지합니다.

저장과 이어하기
호스트가 모든 캐릭터를 저장하고, 친구 PC에도 같은 사본을 보관합니다.
호스트 저장: 실행기 폴더의 saves\host\current.json
친구 사본: saves\replicas\저장ID\current.json
각 폴더의 history에는 이전 저장본이 남습니다.
게임이 캐릭터를 저장하는 시점에 수집하고, 상태 일치 확인 후 사본을 갱신합니다.
다음 실행에서 같은 호스트의 저장을 전원에게 전달합니다.
2인으로 실행해도 사용하지 않는 세 번째 캐릭터 저장은 보관합니다.
원본 개인 세이브를 가져오거나 덮어쓰지 않습니다.
업데이트할 때 saves 폴더를 보존하세요. 새 실행기 폴더로 옮길 때도 함께 복사하세요.

전투 중의 위치를 그대로 재개하는 저장은 아닙니다.
일시적인 통신 장애에는 게임을 멈춰 두고 같은 창에서 같은 위치로 이어갑니다.
입력을 순서대로 재전송하고, 처리한 입력은 중복 적용하지 않습니다.
실제 진행 불일치·게임 충돌에는 게임 창을 다시 열어 스테이지 시작 지점에서 복구합니다.
실행기 창은 닫지 마세요. 친구는 원래 2P/3P 자리를 유지합니다.
스테이지 재시작 시에는 해당 스테이지의 미저장 진행이 되돌아갑니다.
게임 창을 닫으면 방 전체를 종료하므로 마지막 저장 이후 진행은 잃을 수 있습니다.
시작 지점이 없는 화면에서 충돌하거나 스테이지 복구가 반복되면 저장본을 유지하고 타이틀로 돌아갑니다.
단순한 연결 재시도는 스테이지 복구 반복 횟수에 포함하지 않습니다.
이때 1P가 다시 시작하고 각자 저장 캐릭터를 선택합니다.
최대 약 5분간 재접속을 시도하며, 호스트 실행기·PC 종료 후에는 새 방을 열어야 합니다.
호스트 PC를 바꾸면 실행기를 종료한 뒤 saves\host 폴더를 옮기세요.
호스트 저장이 사라졌다면 친구의 해당 replicas\저장ID 폴더를 새 호스트의
saves\host로 복사할 수 있습니다. 기존 host 폴더는 먼저 다른 이름으로 백업하세요.

인터넷 접속
호스트 공유기에서 TCP 47624를 호스트 PC 내부 주소로 연결하고,
Windows 방화벽에서 실행기를 허용해야 합니다. 실행기는 설정을 자동 변경하지 않습니다.
친구에게 공유기에 표시된 공인 WAN IPv4 주소와 방 코드를 전달하세요.
주소에 http:// 또는 :47624를 붙이지 않습니다.
게임 창이 뜨기 전 timed out은 서버 연결 문제입니다. 주소·포트·호스트 대기를 확인하세요.
자동 중계 서버는 제공하지 않습니다. CGNAT·이중 공유기는 추가 설정이 필요할 수 있습니다.
TCP 통신 자체는 암호화하지 않습니다. 방 코드는 매번 새로 생성됩니다.

종료와 문제 확인
플레이 시간 제한은 없습니다. 온라인 일반 진행에서는 리플레이 녹화와 시간 경고를 끕니다.
참가자 한 명이 게임 창을 닫으면 방 전체가 종료됩니다.
문제가 발생해도 마지막으로 확인된 저장은 유지합니다.
logs의 최신 실행 폴더에서 bridge.txt, result.json을 확인하세요.
호스트의 events 폴더에 연결 복구·진행 차이와 각 참가자의 상세 진단을 모읍니다.
진단을 전송할 수 없는 경우 각자의 frames.failure.json에도 남깁니다.
진단 자료는 방의 호스트에게만 보내며 외부 서버에는 올리지 않습니다.
공격 명령은 전체 스크립트의 지문과 상대 위치로 비교합니다.
모든 기술·스테이지와 서로 다른 PC의 장시간 진행을 완전히 검증한 것은 아닙니다.
recovery.json에 복구 이력이, recovery-번호 폴더에 복구 이후의 게임 기록이 남습니다.

한글화
한글 싱글·온라인 실행 시 한글 메뉴·스테이지 대사·직업명·기술명·전투 안내를 자동 적용합니다.
584개 대사·메시지와 495곳의 메뉴 그림 글씨를 번역했습니다.
원본 PAC와 실행 파일은 보존하며, 한글 변경분만 임시 복사본에 적용합니다.
부가 메뉴의 제작진·유저 편지 코너, 음성, 이름 입력 방식은 이번 범위에서 제외합니다.
원본 EXE를 직접 실행할 때에는 한글 패치가 적용되지 않습니다.

검증 범위
한 PC에서 분리된 실제 게임으로 2인·3인 캐릭터 선택, 1스테이지 전투,
저장 사본 일치, 저장 후 재실행, 다음 스테이지 전환을 검사했습니다.
전환 검사는 클리어 조건만 시험 코드로 만들고 게임 원래 저장·이동 처리를 실행했습니다.
자연 플레이의 보스 처치나 전 스테이지 완주 검사는 아닙니다.
서로 다른 PC의 장시간 일반 진행, 모든 기술·스테이지는 추가 검증이 필요합니다.

게임과 배포
본편·EX1·EX2·EX3 PAC와 일본어판 EX3 4.0이 필요합니다. 게임 파일은 포함하지 않습니다.

원본 실행 파일은 디스크에서 수정하지 않고 임시 게임 프로세스에만 적용합니다.
Python은 패키지에 포함되어 있습니다. 라이선스: runtime\python\LICENSE.txt
공식 RBO 프로젝트와는 별개의 실험 도구입니다.
